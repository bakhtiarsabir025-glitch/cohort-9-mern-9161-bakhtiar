# cohort-9-mern-9161-bakhtiar

Cohort 9 — MERN (NodeJS+ReactJS) assignment for Bakhtiar Sabir.

Full-stack notes app: create, edit, and delete notes with user authentication,
built with Node.js/Express, React, and MySQL.

## Tech stack

Node.js, Express, React (Vite), MySQL, Pino, Mocha/Chai, Jest, SonarQube

## Project structure

- `backend/` — Express API, MySQL, auth, logging
- `frontend/` — React app (Vite)

## Getting started

### Backend

    cd backend
    npm install
    cp .env.example .env
    npm run dev

Runs at `http://localhost:5000`. Health check: `GET /health`

### Frontend

    cd frontend
    npm install
    cp .env.example .env
    npm run dev

Runs at `http://localhost:5173`
